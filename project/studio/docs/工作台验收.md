## 未验证与当前限制

- **没有通过真实浏览器视觉验收。** 当前执行环境内 Chromium 创建进程套接字被拒绝；可用云浏览器无法访问执行环境回环端口。DOM 测试不证明 CSS 排版、真实手机触摸或下载保存对话框表现。需要 HTX 上实际打开页面完成最后视觉检查。
- Windows 启动器已提供；本轮本地没有 Windows 系统，不能把 Linux 测试说成 HTX 实测。仓库既有 CI 在 Windows/Ubuntu 运行 Python 测试，具体结果看 PR 检查。
- 本版本不自动驱动 Antigravity，不自带模型，也没有后台任务或实时多端同步。可通过文件交接与命令回收使用现成代理。
- 语义一致性与文学质量由 Codex/人工审稿判断。程序检查版本、顺序和引句存在性，不证明原句能支持结论。
- 长篇尚未实现分卷摘要压缩和上下文预算；按章顺序工作，早章改动可能要求逐章重审。先用开篇三章校准质量与操作成本。

两库的主分支与已有研究 PR 均不自动合并或改写。交付的是功能分支与可审阅 PR。
