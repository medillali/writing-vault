# 原Novel工作区入口与创作框架快照

本目录保留父工作区AGENTS.md、novel.cmd、小说工作台、设计框架与原计划入口。它们是可恢复的布局快照，文中的相对路径按原Novel父目录解释；网页端请优先使用[跨端协作入口](../../COLLABORATION.md)和[当前状态](../CURRENT-STATE.md)。

需要恢复原本机布局时，在Novel/下将本目录的AGENTS.md、novel.cmd、小说工作台.md及docs/按需复制到父目录，与distill-novels/、writing-vault/并列；先检查目标是否已有人工修改，不自动覆盖。原执行资料在project/planning/，恢复到Novel/.planning/后才满足其中旧脚本的路径假设。旧脚本是过程记录，不能未经检查整批重跑覆盖现有精编稿。

正式资料库仍只有writing-vault/，不从这些快照重新建库。
