# 剧情地图与人物库的内容重整

## 用户目标

当前内容过于碎片化；优先整理能服务之后创作的剧情地图和人物库。保留既有研究及证据身份，依据原文复核，不能以卡片数、图节点数或全章覆盖代替内容质量。

## 当前阶段

1. 现状审阅：检查六部已全量研究作品、两部局部研究的入口、剧情结构和人物身份；完成结构核查，文学内容继续逐书核读。
2. 明确审阅标准：方案取舍与纵横全书地图/人物实际样稿完成，资料库结构核验通过；内容满意度仍待用户判断。
3. 用户方向反馈：已确认先内部完成全书脉络理解，不需产出长篇梗概；输出重点为地图探索与创作研究。
4. 正式内容重整：纵横第一套样板落地（47人物主档、13重点人物创作分析、7全书线、18关系）；其余书尚未完成本轮重整，不得标全项目完成。
5. 内容核验：纵横73个事件登记、505处互链与来源哈希核验通过；标准全库validate通过（2891卡/8源/8图/无原创项目）。独立文学满意度仍需用户具体反馈，不由结构校验替代。

## 约束

- 本轮从内容入手，不主动开发新界面、不新增未请求的原创作品，不以目录重排冒充内容重整。
- 两本仅开篇研究的作品保留明确边界，不自行补写全书结论。
- 公开仓库的可见性不代表已上传最新研究；本轮未授权的Git上传不执行。
- 使用本地既有库和检查点，不重新建库。用户评价保持未确认状态。
- 采用brainstorming进行方向核对；用户已确认全书因果地图与人物档案方向并指定地图探索/创作研究为输出重点，按此执行，无需再次询问抽样或逐卷确认。

## 验收问题

读者能否不翻多张阶段卡，就解释一条剧情为何启动、如何升级、在哪个选择分叉、付出什么、怎样影响下一条线？能否在一份人物档案中读清其目标、矛盾、行动、关系变化和结局，并回到对应剧情事件及证据？
