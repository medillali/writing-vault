## 怎样读这张树

蓝色为主线，青色为旁线，紫色为暗线。因果用实线，铺垫、揭示、转折和回收用虚线，主题呼应用细点线。细蓝点划线没有箭头，只负责主干阅读衔接，点击后明确提示不表示因果。

金色交汇标记说明多条推进关系接入**同一个事件框**；线条在空中交叉不算剧情相交。图内已有27处分枝、40处交汇；尚未建立前因关系的事件保留独立起点。阅读导引不计入这些语义统计。
