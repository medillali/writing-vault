## 九维判断

**世界观。** 最有用的设定并非更大的伤害数，而是会改变决定的资格、距离和维护：北冥到275才能实际拿；凌月用77%减速及五分钟资源判定胜天域；命运诅咒对卡伦只降5%、对明宇直接MISS。天域是门槛，仍不是无条件胜负标签。地理同样会承担后果：黄金被天灾毁而非主角攻得；鸿沟阻美国援，催生兽魂战；一剑破墙又造天坑，还需韩信填平。见 raw1068、1085、1143、1160—1166、1176—1177。

**人物。** 书生从护眼前的人走到接无法拒绝的责任：活祭救冰兰、神谕下拒只保自身的无敌，最终仍没把她带回。他也借资本和群体权力报复荀方、强迫天下成员退会。温情与强权都应保留。安妮被救后拥有讲述、提供秘密、拒争王位和担当上将的行动，避免只成为被净化的奖品。现实姐妹经营、冰茶审合同、香亲口拒祭祖，也提供不同于面板的能动性。见 raw1107—1109、1135、1161、1168、1170—1174、1177—1181。

**情节。** 资源在任务之间流动：S6材料、证、装备、比赛奖励、魂10、天域，最终投入国战和终战；高奖北冥最后真碎，阻止积累无止境保存。猎捕安妮是成功，黑暗城堡大战却失败；天地灵恸系统成功，人物愿望却留缺口。任务、战役、私人愿望应分三本账。结尾也只结束主人公征服阶段，佩妮娜与国战仍在。见 raw1067—1068、1090、1149—1151、1159—1160、1179—1181。

**文风。** 数值条目、系统铃声、粗口和英文缩写让稀有物立刻变成情绪；同样密集的巨伤容易通胀，真正有重量的是镜碎、北冥全毁和冰兰缺席。喜剧把神级力量拉回日常：龙域账单、罚单、春字营无人跟、完本短信；物件又能转向哀悼。频繁女性身体凝视、民族化贬抑和性羞辱不能当可迁移优点。可学的是动作、温度、触感和物的用途改变。见 raw1147—1150、1164、1168、1172、1179—1181。

**叙事。** 第一人称书生会自信、猜测、炫耀；第三人称密室让读者先见荀中山的目标，主角并没在场。冰兰公开说净化约五成，私下承认一成就不错，是菲雅、书生、读者之间的认知差。安妮净化后才实际成功；不能倒过来把此前五成当精确规则。冰川末笑声只在主角感觉中若有若无，不足确认苏醒。见 raw1094、1112、1155、1170、1181。

**对话。** 秦韵说愿留但可离，冰茶说不当婚后小三，许芳不反姐妹同在；这些是不同主体的条件，不是自动拼成全员协议。香先让主决定，最后自己反驳以祭祖形式压人的孝道。指挥对话也靠具体条件成立：引安妮的复活、冰封、音律与无敌撤离计划遭额外克莱尔打乱；终战采纳林霜建议，等NPC发动。见 raw1119、1150、1155、1157、1169、1173、1175。

**节奏。** 重复磨女娲、常规两局赛事被压缩，改变方案的测量、魔免克制、诅咒虚招则展开。终战反转依次改变可用物与目标：假体、镜碎、天灾、圣盔入口、北冥碎、圣者探头；有效但密度也高。一个月跳时压缩飞升与荀报复，半年后记处理就业、婚姻、公会衰退，使终战有真正后果；代价是部分重要结果仅用转述结案。见 raw1067、1143—1149、1174、1177—1181。

**主题。** 玩家死亡能复与NPC死亡、生命封冻不共量。“我们会永生”允许主角挡在NPC后路，随后大奖却无法补偿想留下的人。结尾每月探冰、接账单、亲友各自谋生，说明成长也包含接受阶段结束。群体重聚带甜味，并没有消除导师缺席，也没消除所有竞争。见 raw1159、1177—1181。

**连续性。** 源文异常不替作者强圆：活祭数值、永恒进阶层级、17殿名及末人数、已迁沪后又返苏州、局部赛制/人名/分类都有记录。股权则先区分“凌天个人所持份额的10%”与“总股7%以上”，不急判同分母矛盾。末态必须按证据分：明宇确灭、圣者封禁、冰兰未确醒、恶灵续敌、主雪未实婚、龙魂林霜婚礼尚后天。见 analysis 的异常台账。

## 精选场景的机制用途

| 场景 | 可迁移的动作链 | 失效边界 |
|---|---|---|
| 女娲精测纠正满血错觉 | 失败观察→可靠测量→改变方案→压缩循环 | 不把假说写成已验证规则 |
| 凌月耗胜雪夜 | 属性劣势→改胜利指标→距离和资源管理 | 依赖减速、距离、时间判定 |
| 紫月救国内半决 | 保留小角色争取机会→利用隐身时间轴→团队翻盘 | 反隐与硬时限会破法 |
| 活祭救冰兰 | 明确可损资源→自愿选择→真实损失→关系改变 | 不能硬圆有冲突的降级数字 |
| 猎捕与末日深渊 | 局部目标成功→救援扩大→不可逆战略败 | 成功不清除损失，不把毁城算占领 |
| 兽魂破墙与填坑 | 强力解旧障碍→产生新障碍→别职补完 | 不让一种力量自动包办所有用途 |
| 洗碗/龙域账单 | 日常用途→共同生活→失去后接责 | 不靠单纯象征或重复煽情 |
| 神谕下抱住冰兰 | 自护技能不能护人→选择承担伤害→只救局部 | 仍没救全军，也未保证最终挽留 |
| 半年后重聚 | 分别有实际去向→主人公重心改变→有限再会 | 不把重聚写成所有感情身份已解决 |

8张机制卡给出的均是结构实验与原创改造方向，不复制神殿名、装备数值、事件组合或人物话语。用户审美、收藏和原创设定均未代填。
