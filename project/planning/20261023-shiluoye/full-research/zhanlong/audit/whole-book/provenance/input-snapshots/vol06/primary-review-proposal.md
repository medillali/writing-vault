原章1385已再次BEGIN—END全文核读，99582—99590布盾护引线后炮仍发；99594快兽难瞄/瞬杀；99607—99620西门破后才收到开幕倒计时。没有雨已停炮证据。

## 1. analysis.json / dimensions.worldbuilding.0.facts.0.text

原："龙谷要以食物、河道和生态引龙；地雷使用库存火药，泽城最后神威弹打空；北伐补炮来自新采晶/一个月128门制造，鬼城又因粮尽、炮潮受困。"

拟："龙谷要以食物、河道和生态引龙；地雷使用库存火药，泽城最后神威弹打空；北伐补炮来自新采晶/一个月128门制造，鬼城又遭粮尽与炮引线受潮风险；防雨后炮仍能发射。"

理由：同义事实澄清：受潮是风险，不能写成已哑炮。

## 2. analysis.json / dimensions.pacing.2.facts.0.text

原："鬼城先墙高炮多→野战半败→墙破人半→马粮尽→三万取粮被伏→哗变三千出死→雨压火炮→西破城，才外援短时开口。"

拟："鬼城先墙高炮多，随后野战失利、墙损减员、马粮尽、三万取粮遭伏、哗变三千出城被杀；敌待雨进攻，但布与盾甲护引线后炮仍能发射。快兽难以瞄准或瞬杀，西城门城墙仍被砸破；外援再提供短时开口。"

理由：用先后事实代替“雨压炮→破城”的歧义因果链。

## 3. analysis.json / dimensions.continuity.3.title

原："历史未决串保存后用新证更新而不删除"

拟："长期承诺由不同状态的再出现分步回收"

理由：将研究索引流程改为小说实际的承诺回收机制。

## 4. analysis.json / dimensions.continuity.3.interpretation.text

原："逐章未明索引保原话与读者，再以终点问题池说明已答/未答，避免只挑研究者记得的谜。"

拟："职位正式授任、身体恢复、营业资格和授权签字的再次出现，使不同旧承诺分别获得可见回收；秦皇空棺、长老回赠与旧贪查仍留空缺，完成感因而是局部累积，并非一次全清。"

理由：保原facts/全部证据与未闭项，只把解释改成文学内容。

## 5. analysis.json / dimensions.continuity.3.limits_and_counterevidence

原："真正后证缺失只称本卷未明，不宣作者遗忘；卷3prefix之外前史未冒全文实读。"

拟："本卷没有给出秦皇尸去向、回赠长老和旧贪查的完成场面；相似资源在别处再次出现，也不等于该项旧承诺已经兑现。"

理由：移除亲读边界/流程措辞，保小说内回收不充分的限制。

## 6. analysis.json / dimensions.continuity.4.title

原："异常保存为源疑点不扩成新世界规则"

拟："命名与数值漂移增加连续阅读负担"

理由：把操作规范标题改为连续性实际效果，不把源差当优点。

## 7. analysis.json / dimensions.continuity.4.interpretation.text

原："证据可验证的是字面不一致；原因可能误写/统计范围变化，应把修辞推断与事实区别。"

拟："同一神尊的名字、神格品级与兵力口径变化，会使读者更难辨认实体、比较损益和追踪因果；后来明确的行动结果能限定部分理解，却不能消除所有字面歧义。"

理由：去研究方法口吻，说明对读者因果确定的影响。

## 8. analysis.json / dimensions.continuity.4.limits_and_counterevidence

原："检查通过只证明定位和结构，不证明每个解释成立；当前全部待主审。"

拟："未获解释的命名和数值差异会削弱读者对同人、位阶与损失规模的确定判断；结局成功不能替这些差异补出唯一解释，它们仍是连续阅读的负担。"

理由：去“检查通过/待主审”流程，限定为文学局限。

## 9. analysis.json / dimensions.continuity.4.facts.0.text

原："同段空间神尊名乱码/异写、冬茗格中上位漂移，三千余撤兵/五万禁军等有口径差；不补未经解释的隐身或复活使算术圆整。"

拟："同段空间神尊名乱码/异写、冬茗格中上位漂移；祝海三万禁军出队与随后景音所称五万禁军存在口径差。"

理由：同一待修观察内的数词澄清：三千是另一次孙方霖出城，不能当此源差。
