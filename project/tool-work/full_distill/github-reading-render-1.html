降临战斗天使：分集人物研究 借原萝茜身体降临的七阶战斗天使，与原萝茜人格独立；第6集封印后，第7集其意念已被黑龙吞噬并作为信仰元力知识来源。
隆克多：分集人物研究 第13集以魂分解保命后至多侯爵级，未见本集明确恢复原皇帝实力的说明。现追随黑龙进入遗迹与归途，听使命而动摇存在意义；君王经其灵魂中的联系定位黑龙。
雷克丁：分集人物研究 雷神团长、撒拉丁部落族长，受水战条件限制而亡。
雷奥形死息傀儡：分集人物研究 本卡保留第10生成的无意识衍生形态记录；第16明确其吞噬枪中灵魂后进化为灵魂傀儡、恢复雷奥神智，当前人格进展衔接雷奥卡。
雷奥：分集人物研究 噬魂枪中的无意识阶段之后，现因吞魂进化为恢复神智的灵魂傀儡。
霍夫曼：分集人物研究 召集旧学生和强者开启遗迹，因遗漏不会飞行的黑龙，被切罗曼尔分身愤怒灭魂，灵魂之火彻底熄灭。
魅：分集人物研究 弱小亡灵元素体，在圣光损耗下仍为朋友截击祷言牧师。
黑七：分集人物研究 继续参战的黄金骷髅，伏击中再受骨伤。
黑二：分集人物研究 已有自主意识的黄金骷髅子民，与黑大率不死骑兵投入深渊战，部队损失惨重；个人仍无死亡或新阶位证据。
黑四：分集人物研究 伏击中左臂脱臼的孩子。
黑大：分集人物研究 已有自主意识的黄金骷髅子民，与黑二被召至前线并率骑兵冲击魔物，骑兵团遭受惨重损失；没有其个人死亡、再次进阶或意识消失的新证据。
黑龙：分集人物研究 混沌之灵与人工光明神格的承载者，终卷经试战、吞天使和五力量分身回收补足储能；五身为受控力量而非独立人格。最后交出子民君王烙印，接受公正神格，主动消融肉骨投本源；后记未知多少年后意识醒来、跨界回望并重新实体化，明确存活归来。
龙焰（不死巨龙）：分集人物研究 龙墓抢救骸骨中最大者被复起成黑色巨龙坐骑；与已死亡同名不死战马区分。
龙焰：分集人物研究 黑龙长期乘骑的不死战马，伏击中灵魂之火碎灭。
