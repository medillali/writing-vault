# 跨书机制入口

从[五书写作机制比较](写作机制比较.md)按奖励、组织、配角、性格代价、关系、胜负、战术和认识边界八个问题进入，链接各书已主审综合与阶段证据。《纵横天下》《天下无双》《斩龙》整书研究均已独立验收，实际范围与研究条目见[三书最终验收](三书最终验收.md)。蜗牛既有全书任务完成《贼胆》463单元与《练级专家》387单元研究，见[全书入口](../two-books-full-20261025/README.md)及[双书比较](../two-books-full-20261025/COMPARISON.md)。下方旧开篇比较保留原论证范围，不用新覆盖倒填旧报告。这些是研究归纳，尚不是用户已接受的风格规则。

## 从要解决的写作问题查材料

| 写作问题 | 可对照材料 | 目前可研究的差异 | 使用边界 |
|---|---|---|---|
| 怎样让生活压力推动故事 | [《纵横天下》行动物件](../../views/scn-1a25dfdf47594f239e429c41365d2d39.md)、[《贼胆》护手与买饭](../../views/scn-zeidan-legacy-s0002.md) | 前者通过物件归属及工作机会接入游戏；后者通过身体风险和一顿饭让谋生困境具体化 | 不把贫穷当成自动美化一切行动的理由；保留选择及代价 |
| 如何用小动作建立关系 | [《纵横天下》分粥](../../views/scn-3094f1e551584ae0bb89d1fd84d8677b.md)、[《贼胆》石板与领口](../../views/scn-zeidan-legacy-s0001.md) | 一个是初遇印象被资源分享修正；一个是既有关系通过双方照料显现 | 单次善意不能证明永久亲密，也不能取消双方各自目标 |
| 主角已有知识，怎样仍有阻碍 | [《贼行天下》信息交易](../../views/scn-17180b1bbfca4b4cb81cf0a134e02979.md)、[知识优势的机制卡](../../views/pat-711d834b5c334a0095715e49342c8403.md) | 把知识与资金、技能、关系分开；优势须经过交换才能转成行动条件 | 前世记忆不是当前结果；误导交易对象的信任代价不能删掉 |
| 如何让道具承担多种功能 | [《纵横天下》道具机制](../../views/pat-aac351ddab9f40c48f5825fad06c1a70.md) | 同一物件连续改变关系、行动条件和任务，减少无关偶遇 | 学习功能组合，重新设计道具、人物和后果，不搬用原场景 |
| 怎样显示人物改变而非直接宣告 | [《贼行天下》重新相遇](../../views/scn-668f15788d40447eada6c7aad694716d.md) | 用回应方式的差异显示经验变化；仍保留对方不知道的背景 | 主角的回忆和对方当下的感情不能混为一谈 |
| 怎样查找长篇人物变化和未解线 | [《贼胆》人物/场景](../zeidan/cards.md)、[剧情线台账](../zeidan/threads.md) | 同一人物按阶段留档，连同原观察时间、矛盾和疑点保留 | 阶段状态不是结局状态；183份人物材料不是183个独立人物 |

以上旧《纵横天下》链接的论证范围为前5章，《贼行天下》为前4章。《贼胆》条目迁自旧库的逐章研究，完整来源与版本保存在卡片内。连续分卷研究从[《纵横天下》专题](../zongheng-tianxia/README.md)进入。

## 《纵横天下》连续阅读后新增的机制

以下卡片来自卷一第1—49章；后续的状态兑现和变化另见[跨卷衔接核验](../zongheng-tianxia/跨卷衔接核验.md)。

| 写作问题 | 机制及具体证据 | 迁移时的约束 |
|---|---|---|
| 怎样避免每场战斗只有全赢或全输 | [分开结算目标、资源与损失](../../views/pat-e4733f9eda4252cfa52b29e550e4f306.md)：第30章击杀、取得物品与任务失败并存 | 先列出独立目标与成本，再分别结算；不能用某项成功悄悄撤销已发生的损失 |
| 怎样让馈赠既改变关系也改变行动 | [同一资源推动关系与能力](../../views/pat-dee577175d125b3f95d46547ff7daf91.md)：分粥、赠剑和队伍分配分别改变可用资源及相互回应 | 保留受赠者的选择，不把赠礼自动等同爱情承诺；原创时重新设计人物动机和资源 |
| 怎样让战术可信 | [规则、动作与反馈共同证明战术](../../views/pat-62e3140bf2b859f58f1af870ef86f13a.md)：先展示复活预言规则，后暴露个人受益冷却限制 | 技能施放冷却与同一对象再次获益间隔是两项条件，不能合并成单一“有复活” |
| 怎样把局部行动变成长期声誉 | [战斗结果经证据载体转成声誉冲突](../../views/pat-4cc877c453035aff8606700941fd7ccd.md)：录像使战场选择进入公众判断 | 公开传播需要可见载体及接收者；不能把私下威胁写成全城已知 |
| 怎样分层揭开身份 | [分阶段揭示不同身份](../../views/pat-d2a0cdb773765365a303eb36e5281761.md)：称号、熟人辨认、双胞胎差异分别改变认知 | 分开读者知道、主角知道和旁人知道的内容；误认保留为当时人物认知 |

使用顺序：从写作问题选机制 → 打开派生来源中的场景/人物 → 核对章节与解释边界 → 为自己的角色和世界重设计 → 在卡片用户笔记中记录是否采用及试写结果。研究归纳不会直接变成原创项目设定。

卷二第50—100章补入三个可直接接着研究的方向：[用流程瓶颈分配队员的重要性](../../views/pat-94a43d8d2a955ef0925bb56a30177eb3.md)，把战斗、拾取、护送和交付变成不同成员的必要贡献；[让胜利代价在另一生活层继续发生](../../views/pat-d90348771b225b6aa250d0f60c2cef55.md)，让耗时、耐久与资金消耗改变下一个生活选择；[礼物回流与关系的清账观](../../views/pat-98d6a5f7d7a852e6826bdb7a6d7a915a.md)，观察赠与双方赋予物品的不同意义。这些都是对应阶段的机制候选，不是全书或作者整体风格结论。

## 后续比较的固定问题

另见[旧开篇双书比较](../two-books-20261023/comparison.md)与[六张机制候选](../two-books-20261023/patterns.md)：当时细读范围为《贼胆》前10章和《练级专家》序章＋前12章，这份旧报告仍只支持该范围。后续既有双书任务已有独立的[全书九维与终态研究](../two-books-full-20261025/README.md)及正式检查点；不能用更新后的总覆盖冒充旧报告原本已做全文论证。本轮失落叶研究会与全书成果作新的范围相称对照。

按创作顺序读完每部书后，再检查同一作者是否发生变化：主角优势是否需要代价、关系是否双向行动、团队如何分配资源、数值怎样参与决策、NPC是否有独立愿望、伏笔如何变成后果，以及现实线和游戏线怎样互相改变。

先记录每书的证据，再写跨书推断。不能仅因后书写得晚就认定更成熟，也不能把同一世界名或同名人物当作跨书身份已核实。跨作者比较应优先选择相近叙事阶段和功能，避免拿一书开篇与另一书结局直接评高下。
