# 《纵横天下》完整人物库

[全书树图](tree/index.html) · [剧情地图](map.md) · [创作研究](craft.md)

人物按一人一份完整档案整理。核心人物展开连续的人生阶段；重要配角按材料详略处理，串联身份、性格、心理、行动、关系与终点。外貌、年龄或创伤缺证时保留空缺，不补造设定。

事实与研究解释分开；人物原文定位折叠在每份档案末尾。龙神等未完成实体辨析的称号不强行合为一个人。

## 核心人物

| 人物 | 贯通阅读的重点 |
|---|---|
| [丁舒升／轻狂书生](characters/character-arc-01.md) | 一个从孤独和生计匮乏中重新进入共同生活的人，靠战斗与组织不断扩大保护能力；两次归零教他接受依赖，失亲与终战教他承担无法获胜的失去。情感丰沛、肯付代价，与占有、偏私及报复同时成立。 |
| [凌雪](characters/character-arc-02.md) | 由醉酒受助者，成长为主动带练、会提出战术与伦理要求的搭档，再从公开恋人走向必须接掌家业的成年人。她的俏皮、勇敢和护短并行，失亲后的成熟体现为新的承担，而非从此没有脆弱。 |
| [凌月](characters/character-arc-03.md) | 她的长弧是从受期待和制度掣肘的年轻总监，走向能调动组织、争回经营权并接续家业的人。经营能力和私人脆弱一起存在；渴望作为凌月被理解，比“理性的姐姐”标签更能解释其关系张力。 |
| [秦韵](characters/character-arc-04.md) | 一个能经营公司、救同伴、温柔照料他人，也想被爱和被珍惜的成年人。她反复受恩情与亲情义务牵制，又通过离开、拒绝与重新选择维护自己；全弧的重点是能力、欲望和边界如何彼此拉扯，而非只给主角安慰。 |
| [许冰／冰茶](characters/character-arc-05.md) | 一个会让共同体运转、能战能管也争自由的人。隐瞒病情使她的戏谑被重新理解，治疗后的专业工作与独立事业又把她从“等待被拯救”中继续写出去；亲密、离开与重逢都保留她自己的条件。 |
| [林香／稻花香](characters/character-arc-06.md) | 她的成长不是由坏人变好人，而是原本有道德选择、却缺少行动条件的人，逐渐获得安全、康复、合作位置与拒绝旧控制的能力。最有分量的终点，是她终于能亲口说明自己愿意和谁生活、为何不回去。 |

## 龙域、王国与亡灵线

| 人物 | 贯通阅读的重点 |
|---|---|
| [冰兰](characters/character-arc-07.md) | 长期独守龙域的强大导师，在书生身上获得传承之外的牵挂；她经历受救、道歉、净化与杀师，最终以生命冰封换来大陆生路，把未完的龙域与思念留给徒弟。 |
| [安妮](characters/character-arc-08.md) | 从人类女王到被魔兵奴役的霜之剑刃，安妮始终残存护妹之情；被制服并净化后，她以情报、战斗和拒绝复位重新选择自己的位置，最终作为上将与菲雅继续守护联盟。 |
| [菲雅](characters/character-arc-09.md) | 在姐姐的英雄遗影和国家期待之间成长的军事统帅；战争令她不断失去部下，却仍为救回姐姐争取机会。姐妹团圆后，她接受姐姐支持，继续以女王身份承担未完的战争。 |
| [明宇](characters/character-arc-10.md) | 曾为龙域守护传承的前代导师，在魔兵力量中变为毁灭深渊；他重创学生、奴役女神并试图唤醒圣者，最终被冰兰连同黑暗魂格彻底毁灭，留下仍须生命冰封收束的灾厄。 |
| [灵儿](characters/character-arc-18.md) | 从幻灵珠中获救、刚失去母亲的少女，在与书生相伴和反复互救中逐次解除三道封印；最终成神仍需重练，也仍会发问和依靠，结尾以陪伴承接未能挽回的失去。 |
| [林克](characters/character-arc-20.md) | 为安妮断后而被困死亡洞穴的护卫队长，亡灵化后仍完成战甲，却只把权杖气息误作重逢；他给艾兰的未完承诺由书生接续，人物因此在死亡之外留下照顾与生活的余波。 |
| [林丘](characters/character-arc-21.md) | 有判断力的年轻副将在丧妻后披上米拉的遗物继续从军，断臂又受为兄复仇牵动，最终为救菲雅被达尔掏心、斩首。他留给后文的是纪念和损失，而非凭同名复活。 |
| [奥丹](characters/character-arc-22.md) | 奥丹从敌对游侠转为保护人类的一方，并不是净化一完成就换阵营。她对人类暴政的旧恨、留下的人心与梦境中的具体遭遇，共同解释其后续选择；最后的牺牲仍是独立结果。 |
| [大巫师](characters/character-arc-23.md) | 大巫师的救援能力与旧怨绑定。她不是随叫随到的治愈工具：借杖、活祭和道歉把救人变成必须支付的关系与行动成本，随后她自己也进入危险。 |
| [逐风者卡伦](characters/character-arc-24.md) | 卡伦的多次出场先展示主角无法跨越的力量，再让战争、复魂与识破幻身改变对抗方式。他的第一次死亡和最后形魂俱灭是不同结果。 |
| [魂殇](characters/character-arc-25.md) | 魂殇的经历先从被欺与未尽愿望转化为可召战力，后来又以永久失去结束。若只把他存作一次召唤技能，就会丢掉能力的私人来路和损失的重量。 |
| [达芙妮](characters/character-arc-26.md) | 达芙妮先被救，又反过来救援和保护别人；她在胜利战役中的死亡，保留了群体成功不能结清个体损失的事实。 |
| [米拉](characters/character-arc-27.md) | 米拉的等待通过最后会面结束，但她与林丘的生活没有因此被修复。婚纱与披风使这段私人关系跨过任务结算，进入丈夫后续的战场。 |
| [血吼](characters/character-arc-28.md) | 血吼是龙域叛乱的行动者，同时用龙神之名为自己建立权威。他的死亡解决一场战斗，却立即让明宇的更大威胁进入现场。 |
| [亚兰](characters/character-arc-30.md) | 亚兰是导师旧案中另一个缺少尸体的人，后来以自述和现场行动显露背叛。对他的揭露回答了部分调查问题，却没有自动回答明宇的去向。 |

## 组织、盟友与竞争者

| 人物 | 贯通阅读的重点 |
|---|---|
| [七星灯](characters/character-arc-11.md) | 七星灯是能够持续重组资源与归属的竞争者。他与书生争胜，却也能交易和协防；失败改变筹码，没有把他从故事世界中删除。 |
| [野蛮王座](characters/character-arc-12.md) | 野蛮王座承载的是另一方领袖的持续竞争：他能展示个人强度，也要为部众、领地和撤退作选择。多次失败不意味着现实死亡或退出历史。 |
| [荀方](characters/character-arc-13.md) | 荀方把财富、社会关系和游戏资源用来接近凌雪；被明确拒绝之后仍转换手段。他的失败跨越人物关系与组织竞争，但终点不等于所有现实后果都已结案。 |
| [一粒尘埃](characters/character-arc-14.md) | 一粒尘埃的线索把高水平操作、旧会忠诚、未获确认的爱意和重新谋生放在一起。真正的转折是他与很萌很好推怎样共同选择重开，而非删号之后无代价回到原点。 |
| [很萌很好推](characters/character-arc-15.md) | 很萌很好推需要作为会长、旧关系中的当事人和主动选择伴侣的人独立阅读。她拒绝将尘埃贬为打手，随后亲自寻找和共同重建，使关系变化有了双向行动。 |
| [暗影随风](characters/character-arc-16.md) | 暗影随风的主线不是换过几次公会，而是他在个人尊严、新归属与旧恩之间怎样作出不同选择。最后的婚姻与淡出又使游戏组织回到人生的一部分。 |
| [林霜](characters/character-arc-17.md) | 林霜以组织和商业判断维持战魂位置，个人操作并不总与领袖地位相称。她的外交、战场意见与私人关系形成不同层面的主动性。 |
| [烛影乱](characters/character-arc-32.md) | 烛影乱以国际赛中的高操作对手进入本书。他承认一场比赛中的差距，随后回国建立烛龙；这条线的终点是新的竞争力量出现，不能借后作替本书补完。 |
| [红绫舞](characters/character-arc-37.md) | 红绫舞经历从敌盟核心、替王俊杰经营事业，到现实伤害后的组织重建与有限结盟。她的弧线必须同时保存受害、依恋、经营能力和重新选择，不能只写成由男主救回的女人。 |
| [孤坟](characters/character-arc-38.md) | 孤坟把友谊、资源交易和势力自主同时带进主线。他能帮助雪月，也会保留秋雨与亲属关系的利益；人物的可信处正在于不是无条件输送资源。 |
| [王俊杰](characters/character-arc-39.md) | 王俊杰把职务、财权和名义婚配带入对凌月与书生的压迫。其权力受挫后依靠红绫舞重新立足，最终现实死亡；这条线包含许多转述与判断，不能写成一份已结案的犯罪传记。 |
| [林傲](characters/character-arc-40.md) | 林傲既是傲世的竞争者，也是林香需要摆脱的现实控制关系之一。末尾他仍活着并试图以亲缘要求林香同行，她明确拒绝，构成这条关系真正需要保存的转折。 |
| [龙魂](characters/character-arc-41.md) | 龙魂由剑火的互助骨干进入雪月，又为旧有记忆带剑火离开。他的离开没有取消兄弟关系，后来的共同国战与生活安排表明组织归属和私人情义可以分开变化。 |
| [沈落雁](characters/character-arc-42.md) | 沈落雁既是七星灯的现实伴侣，也是公开争执中的当事人。她的自述、组织意见与日常陪伴应独立保存，不能只作为七星灯受辱或发怒的理由。 |
| [血饮天下](characters/character-arc-43.md) | 血饮天下在敌盟中以权力和公开羞辱制造裂痕，后仍参与势力争斗，最终由凌天报告其现实死亡。组织冲突、性羞辱言论和现实案件是不同证据层，需分开处理。 |
| [命运魔方](characters/character-arc-44.md) | 命运魔方的核心不是被高价买走的神射手，而是如何兼顾旧会知遇与更好的战斗条件。他通过分盟方案加入合作，保留旧关系；末尾转向酒店经营，也使人物拥有游戏之外的生活。 |
| [勇敢的心／艾妮](characters/character-arc-45.md) | 勇敢的心／艾妮由法国区强敌转为有限合作伙伴，后来进入中国账号体系、追随冰茶并继续跨区协作。她的选择受妹妹、组织和局部承诺共同影响，不能用国别一次性规定忠敌。 |
| [冰之逸](characters/character-arc-46.md) | 冰之逸的成长把职业名、实际坐骑和指挥职责分成三个阶段。她要求凭实力获得位置，取得龙蛋后仍需成长，后来才成为独当一面的空中力量与组织领导者。 |
| [流年花火](characters/character-arc-47.md) | 流年花火与冰之逸共同进入新一代龙骑队伍，却有自己的资源取得和前线行动。她从争取机会，到幼龙阶段，再到侦察、空袭与先行冲锋，不能只写成另一位龙骑的附属标签。 |
| [雪见草](characters/character-arc-48.md) | 雪见草的弧线是第二治疗如何逐步成为能独立承担团队续航的人。她起初装备弱于秦韵，后来通过赛事、职业成长与多次补位赢得位置，现实婚姻则让她拥有战场之外的结局。 |

## 现实生活与工作室

| 人物 | 贯通阅读的重点 |
|---|---|
| [凌天](characters/character-arc-19.md) | 凌天既是姐妹的父亲，也是掌握公司资源与安排权的人。后来的临终解释改变书生对他的理解，却不能撤销早期施压给年轻人造成的实际处境。 |
| [亡姐（书生旧创伤）](characters/character-arc-31.md) | 书生称为姐姐的亡者，是他回忆、墓地与保护欲的重要来路。作品没有在现有研究中完整揭示其姓名与外部真相，档案应保留这份不完整，而非替她补一部前传。 |
| [许芳](characters/character-arc-33.md) | 许芳在凌天身后回到蓝星，以执行总监和长辈的双重身份提供支持。她的重要性在于能提出意见而不取代姐妹作决定，为家族与企业线提供较温和的续接。 |
| [紫月](characters/character-arc-34.md) | 紫月的成长不靠突然成为全队最强，而是从易被忽视的成员走到主动争取出场，并在适合自己的条件下拿到关键分数。她的价值需要连同失败和队友支持一起看。 |
| [落雨无声](characters/character-arc-35.md) | 落雨无声的存在感主要来自集体作战中的稳定执行。她从工作室弓箭手走到率领射手与护送工匠，在强者叙事之外承担维持团队行动的具体责任。 |
| [夏天](characters/character-arc-36.md) | 夏天从工作室中活泼亲近的成员，逐步进入对自己能力和成年生活的证明。她的战斗选择、现实工作和重聚应连起来看，不能把一次误认写成她早已知道全部关系。 |
