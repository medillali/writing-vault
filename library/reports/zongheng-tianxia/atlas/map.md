# 《纵横天下》全书剧情树

**[打开整书剧情树，沿主干连续阅读](tree/index.html)** · [完整人物库](characters.md) · [创作研究](craft.md)

贯通整书的是这条责任变化：**谋生入局 → 共同生活 → 建会与领地 → 公共战争 → 失去与重建 → 现实事业与龙域托付**。凌雪、灵儿、冰兰和配角的选择在具体事件中接入主干，也保留各自的目标与后果。

[![实际阅读预览：同一事件在树中定位，右侧解释处境、行动与变化](tree/reading-preview.png)](tree/index.html#v1-v1c35)

## 先这样读

第一次打开会从主干第1步开始。左侧31个转折按故事阶段组织，右侧逐步解释**当时的处境、人物怎样行动、这一步改变了什么**；上一转折、下一转折可连续阅读。点相关分枝后，可以返回原来的主干位置。

想先看形状，点“全图”；想看某条线，选左侧7条全书剧情线。搜索支持人物、事件和原章号，并列出可选择的结果。右下小地图标出当前位置；关闭后再次打开会记住阅读位置，带事件链接进入则优先定位该事件。

整张树保留260个事件／场景和227条语义关系，每个事件只画一次。本轮为其中**51个关键事件**补了连贯解释，包括31个主干转折及20个重要分枝；其余事件继续保留原研究摘要和证据，未冒称全部重写。
