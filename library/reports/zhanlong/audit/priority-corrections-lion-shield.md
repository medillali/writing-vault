# 狮王盾规则的优先纠正

本层已由主代理核对原文通过，研究仍待用户审阅。查阅卷三旧笔记、规则异常和“国器争夺把保护后卫的代价可视化”场景卡时，应先读本纠正。

740及744系统公告原文均为“十小时内”，旧摘要误写成“十小时后才可装备”。743仍有9小时17分争夺时间：主先承诺保住后分给，随后遭追击，实际提前交抹、借战膝补足120怒、施放群狮之盾。不能据旧摘要制造“公告禁止、角色违规装备”的源冲突。

这不取消进城、下线、死亡掉落及坐标暴露等争夺限制，也不把期间装备当最终保有或推广所有国器即刻无条件装备。旧notes、卡片版本和读者署名原样保留；[十一字段前后与核源凭据](priority-corrections-lion-shield.json)。
