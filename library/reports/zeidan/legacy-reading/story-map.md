# 《贼胆》故事线总图

这是首轮研究的结构判断，不是作者自称的官方划分。**主／支**表示对全书持续组织剧情的作用，**明／暗**表示信息在什么阶段对人物和读者显露；同一条重要支线也可能先暗后明。以下章节均用文件内顺序号，原作没有分卷。

## 贯穿全书的三个问题

| 编号 | 贯穿问题与主要因果 | 变化与边界 |
|---|---|---|
| M1 现实生活 | 靠盗窃供养妹妹、难以就业 → 试玩头盔提供职业入口 → 技巧、交易、任务带来现金 → 黑赛改变收入级别 → 报答旧日恩人、选择共同生活 → 击败刺刀后完成财富目标 → 计划并启程迁往新星 | 早期是生存，中段变成争胜与积累，后段转为悠闲游戏、关系承诺和安定生活。不是一直处于贫困，也不是后期每次竞技仍为赚钱。 |
| M2 竞技成长 | 失败中理解技能 → 观察不同对手并修正自己的战斗方法 → 商业竞技检验技术 → 获取组织资源、宠物与装备 → 挑战刺刀、公开竞技 → 与萧翎最终较量 | 技术、职业相克、情报、装备与配合共同决定胜负。不能把每场胜利都解释为同一种“天才碾压”；团队二对十也有实际失败。 |

## 支撑这些问题的长期剧情

### P1｜职业能力如何变成经济与组织资源

早期卖装备、草药和配方、受雇完成任务；之后黑赛提供大量现实收入，风野的公会又提供配方、团队、情报与装备。这不是单一“金主送资源”链条：萧御也回馈产出、地图发现、任务成果和竞技胜利，双方能力相互放大。

深白用背包回报剥皮刀，暗狱按约付款，风野投资竞技与公会战争，属于不同交易关系，不能全部归成好友。合作关系是否变成私人认同，要看后续行为。

### P2｜公会竞争与团队协作

公会战争改变任务环境、资源分配与敌我关系，国家战争又改变公会间可采取的行动。风野曾作过于乐观的判断，局势反击迫使他调整策略。研究应保存“当时预测—后来发生—修订”三者，而非把预测直接写进结局。

捕获幽灵比蒙、刺血十盗贼任务与竞技队伍，都展示个人强与团队适配不是同一回事。柠檬承担协调，糖果既不服又会学习、发现办法；风笛主动赴死却没达成预期仇恨转移。配角的选择不能只作为主角能力的旁证。

### P3｜NPC历史、阵营与世界冲突

它由局部委托、历史故事、物品线索逐步连到更大的阵营信息。早期哈蒙斯的血哺与族群延续叙述、古德神殿与圣言匕首、遗失之城的科技史、后期克文图斯与黑暗之主的消息，应分别保留原始来源再作跨段连接。

**层级暂定为重要世界支线。** 它对后期大事件、奖励和能力扩张有重要作用，但不是从第一章起持续压迫主角的唯一中心问题。是否应升格为并列主线，取决于你更重视事件规模，还是持续组织主人公选择的能力。

古墓老人“哈蒙斯／克文图斯”存在名称接续问题：有赠物、经历及后文识别的关联证据，但后文并未总是并用两名，需保留身份解释依据，不静默改名。

**结尾状态。** 两大联盟停止原有战争、共同应对第三方；后期沃顿的肉身被团队摧毁，灵魂进入分身时萧御刺中发光胸口，系统宣布任务完成，他取得残留神格成为下位神。乌服诺斯的反击与探索由此开启，萧御以“肖恩”化名给玩家派任务。世界仍继续运行，人物的生活目标则已可以结束这一部故事。

这里不能补造“找到并摧毁了独立的本命骷髅”场面：末段展示的是胸口融合处的击杀和系统完成判定。沃顿创造生命的动机、主角对善恶双方的评价也应分栏，不能替用户定性。

## 可追踪的物品回响

- **逃脱匕首**：最初是送信回报，带着赠者的生存／族群意义；随机位移既救命也制造新危险；后期又参与身份接续。记录它的规则、使用后果和意义变化。
- **圣言匕首**：任务中给予、成功后降阶、另有清洗条件。获得时的属性、交付后的属性与未来恢复不能填成同一状态。
- **速语项链**：来自NPC爱情任务，后来成为玩家关系记忆；属性落后仍被保留，失而复得带来后果。蓝月有归还意愿，但实际展示的是死亡掉落、萧御推测有意送还。
- **配方、剥皮刀与背包**：物品跨使用者转换价值，并建立人际联系。它们适合记录交换链，不必全部升格为伏笔。
