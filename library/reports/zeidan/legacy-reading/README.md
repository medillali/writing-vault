## 这次最关键的研究结果

- **主人公目标至少分三段。** 最初谋生，中段赚钱并争第一，击败刺刀完成财富目标后又转向自主享受游戏与新生活。静态“护妹升级”不足以解释全书。
- **人物的记录深度不能只看主线贡献。** 小雨的家务与撮合、猴子的烟头、吴大妈的豆浆、燕琳的多次接近与拒绝，都值得单独保存。
- **NPC不是只有任务功能。** 爱情、故乡、占有、族群记忆等愿望与玩家效率会发生冲突。事实、角色自述、主角判断、叙事评价分别保留。
- **结局收束与全解谜不同。** 最终竞技获胜、关系承诺和启程有明确结果；萧翎亲缘、部分历史关系等没有被自动填平，婚约也没有被写成已举行婚礼。

## 用这轮结果改进系统

现有数据已经保存事实与解释的分栏、逐章来源、分段过程和用户评价空值。下一步框架改造需要优先解决：

1. **有证据的身份合并与冲突保留。** 赵医生／夜岚可归赵岚馨；萧御／萧翎不能凭误字合并；学历前后冲突需要双来源。
2. **状态和认识按时间变化。** 预测不是结果，计划不是完成，人物误认不是物件属性，早期未解不是结尾仍未解。
3. **跨段更新要有修订记录。** 后文能更正人物模型，但不能擦掉人物先前的认识和关系状态。
4. **把你的审查接进素材库。** 记录你愿意借鉴、拒绝、觉得被解释扁或遗漏的具体位置，再做小规模原创试验；不先从一本书抽出一套通用模板。

建议先审查六张场景卡：哪些具体东西应该保留，哪处解释反而削弱了原场景，哪种材料让你产生“想写自己的版本”的冲动。你的回答再转成个人审美数据。
