# 主线与暗线图片阅读

用户要求图片形式，并要求整体沿小说主线时间推进，未回收暗线可以明确标注。

采用可保存的 PNG 图片和可缩放的 SVG：全书阶段树、18 集事件推进图、15 条正式暗线的时间总览及逐线详图。保留现有研究文字和证据入口。相比把所有事件压成一张关系网，分层图片可以保持字号和顺序清楚；相比插画故事地图，研究图能准确保留中文事件、证据与回收边界。

全书阶段树使用既有综合报告的七阶段划分；各集短说明是图示摘要，属于研究整理。事件和暗线从 plot-graph.json 读取。按 narrative_order 排列，即主线阅读进度；旧史、回叙、跨段聚合保留说明，不推算新的绝对年代。

蓝色主干只表示阅读顺序。旁路箭头表示已有因果、铺垫、揭示、误导、转折、呼应和回收，保留编号、关系类型及研究判断性质。跨图关系在对应关系说明中标明端点；图与正文共同保留全部依据。长暗线分页，每页保持时间向下推进，不缩字挤入整书。

终点状态统一采用全书复核结论：绿色已回收、琥珀色部分回收、红色未回收。未回收线的虚线延至终点仅表示问题仍悬置，不表示人物在空白期间持续行动。部分回收不等于完全无答案，局部回收也不自动解决同人物其他问题。

验收：核对事件覆盖、暗线完整性、最终状态和文字不裁切；逐张检测尺寸和文本边界，抽看总览、长暗线、回叙集与终集；核对 PNG/SVG 和页面链接；原研究 JSON、人物笔记和历史不变；实际推送并核验私有 GitHub 后报告同步完成。
