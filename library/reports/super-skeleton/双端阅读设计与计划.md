# PC与手机剧情阅读器

目标：让人找到一个事件的全部前因、辨认两线交汇、进入支线后回到原位置。依据用户引用的《设计树状图阅读方式》落实已有方案。

选择：单纯缩放完整图改动少，但手机文字依然太小；拆为静态分图方便保存，但追溯和返回困难；本次采用响应式阅读器，PC侧重局部结构，手机侧重沿线卡片。沿用原数据，无需迁移研究记录；增加独立生成入口及浏览器交互，原PNG/SVG继续可用。

## 阅读行为

- PC先看七个剧情阶段的骨架入口，打开阶段后显示局部关系图；左侧选择阶段、正式剧情线或人物卡，右侧显示事件及全部入边/出边。图中只放标题、位置、交汇与跨范围数量。点击节点只改变高亮，不重新排列；缩放和平移按范围保存。
- 手机默认从第一阶段的核心主线卡片开始。卡片提供摘要、章号、关系数量、共享剧情线和阅读标记。卡片相邻只表示阅读顺序，实际因果、铺垫、揭示、呼应、回收等另列。
- 进入支线、追溯某前因或打开局部图会保存当前范围、选中事件、滚动、展开状态与图位置；“返回刚才”恢复这一快照，与“追溯前因”分开。
- 所有入口共用事件ID、正文及阅读标记。主档判断性质、读者/角色认知、证据行号照原样保留。相同名字的人物卡不自动合并。
- 局部图默认一个事件及直接相连事件，允许再展开一层。远端关系全部列在详情中，明确标注跨阶段/当前范围外，不能静默丢失。
- 页面可离线打开；阅读进度保存在当前浏览器，可导出/导入JSON跨设备接续。导入只接受当前来源、版本、合法事件ID，损坏或异书进度不覆盖当前状态。
- 私有网页部署独立于页面实现。GitHub文件同步不等于手机网页已部署；保持资料私密，访问方式等待用户选择。

## 模块和实施任务

### 1. 数据与阅读状态

新增 `rebuild_reader.py`，生成单一事件索引、46条正式剧情线、七个既有综合阶段、人物卡索引。`reader/model.js` 提供 `createModel(data)`、`scopeIds(scope)`、`relations(id)`、`nearby(id,depth)`、`snapshot/restore` 所需的稳定数据。

- [x] 测试先行：重复语义边不重复计算来路；全部入边出边保留；切换线索共享同一事件ID；返回恢复滚动与选择；异书/坏JSON不能污染进度。
- [x] 实现模型与单文件构建，源研究JSON不改。

### 2. PC分层关系检视

新增 `reader/graph.js` 和 `layout_reader.cjs`。提前计算阶段、剧情线的曲线坐标，浏览器无布局服务依赖。展开或聚焦时复用坐标；前后关系保留原始方向。

- [x] 初始测试确认旧页面缺少阶段入口；实现骨架入口、阶段图、全线/人物筛选、右侧事件详情与范围外提示。
- [x] 图上节点、关系可通过鼠标和键盘访问；标题可读，支持按钮缩放及拖动。

### 3. 手机沿线阅读和返回

新增 `reader/app.js`、`reader/style.css`、`reader/template.html`。同一状态驱动卡片和关系图；窄屏导航抽屉、事件详情独立阅读层，正文自动换行，触摸目标至少44像素。

- [x] 从第一阶段核心主线开始；提供全部事件入口、搜索、交汇、待回收筛选。
- [x] 支线、详情、局部图支持原位返回；布局切换不改变事件内容、阅读标记或已选范围。
- [x] 浏览器当前进度保存、导入导出以及不可用存储降级提示。

### 4. 验证与交付

`test_reader.cjs` 用真实研究数据和Playwright执行三类关键阅读任务；检查320、390、768、1024、1440像素布局、键盘、触摸、图缩放、无外部请求与页面错误。截图分别审阅桌面和手机；源研究数据和旧图片保持不变；阅读目录仅更新入口，新增加1页，共299页，哈希清单同步更新。

- [x] PC：从阶段找到事件全部前因及跨范围关系；节点聚焦时坐标不变。
- [x] 手机：进入支线、追溯两层、查看局部图后返回原范围、事件、滚动位置；共享事件读过标记一致。
- [x] 不同宽度无正文横向溢出；长标题、空结果、储存不可用、进度格式错误有实际可读反馈。
- [x] 更新GitHub入口、打包单文件阅读器，完成最终审查后提交并同步私有仓库；明确手机真实设备与私有部署是否完成。

测试命令：运行 `node reader/test_model.cjs` 和 `node test_reader.cjs`；使用本机可用Node/Python与Playwright，`PLOT_BROWSER_EXE`指向本机Edge。构建顺序：`python rebuild_reader.py --data` → `node layout_reader.cjs` → `python rebuild_reader.py`。

审查重点：恢复状态不得混入其他事件；折叠不得删除关系；同名卡片不合并；离线不请求远程数据；未回收结论不因布局改变；手机返回不锁住滚动；响应式切换不得意外丢掉选中事件。实施由当前任务连续完成，使用已有干净工作树中的功能分支，便于保留本机阅读路径。

最终审查：独立审查发现的四项缺陷均已修复，模型测试和两组浏览器测试通过。双端模拟通过不等于实机验收；私有GitHub同步的实际结果见本次交付提交与工具核验记录。
