# 《贼胆》：本次回读与九维观察

本次完整回读原书第1–10章，对应 `ch-0002..ch-0011`。旧研究的463章逐章记录及人物/场景材料另行迁入；旧成果的内容哈希、章节映射和证据行界经过本次核验，不能据此声称已重审全部语义。以下判断只针对本次回读范围。所有行号可在[完整章节索引](chapter-index.md)对应修订中定位。

## 最值得保存的细节

小雨不是抽象的“主角奋斗动力”：她洗衣、让出干净石板、整理衣领，还主动领取限时试玩头盔。她一面看穿哥哥摸鼻子的谎言，一面为他创造另一条谋生路径。这组动作既建立关系，又改变情节可行性。萧御会赚钱并不意味着小雨只需等待被救；研究卡保留双方行动的不对称和互补。依据：第1章 L27–45；第3章 L188–221。

技能进步也有可检查的过程：潜行因降速打乱步调而失败；反手背刺先被撞断，调整为避开攻击后出手；随后在无敌人的环境中尝试回旋借力。第9章的突破仍受冷却、减速毒和剩余血量约束。值得迁移的是“失败原因—调整—效果—新限制”，不是技能名、百分比或相同战斗场面。依据：第5章 L307–312；第6章 L318–350；第7–9章 L367–456。

## 九维研究

| 维度 | 本批观察与证据 | 创作用途与限制 |
|---|---|---|
| 世界 | 昂贵设备、试玩期限、物品处置权影响职业选择；亡灵抑制必须事前使用，不能解除已中控制。第2–4章 L113–115、199、241–263。 | 世界规则要改变选择。角色认为团队不适合挣钱，是其选择理由，不应升级为所有团队的客观定律。 |
| 人物 | 萧御急需收益但肯慢练；小雨有独立行动；猴子愿以命相交而萧御只视其熟识。第1章 L55–64；第3章 L188–221；第6章 L328–350。 | 关系要记方向与阶段。内在需求属于研究推断，不替代人物行为。 |
| 剧情 | 生活压力→临时入口→职业选择→技能掌握→费用瓶颈→委托义务。第2–10章。 | 局部进步连接下一约束，避免每轮都把状态清零。 |
| 文风 | 外貌、伤口和双手反复被显性评价；战斗段以动作、技能提示和自我反思交替。第1章 L24–45；第2章 L123–168；第7–9章。 | 可控制动作密度、解释密度与感官细节。并未做句长统计，不能把印象报告为测量值。 |
| 叙事 | 读者早知“工作”为借口；小雨识谎却不揭穿；奥德在主角离开后评价其技术。第1章 L33；第3章 L192–203；第10章 L489–491。 | 分开记录读者和人物所知；“未说破”不等于“不知道”。 |
| 对话 | 家庭玩笑承担照料与避免直接刺痛的功能；导师对话明确价格、委托和违约责任。第3章 L192–221；第10章 L470–480。 | 对话要改变关系或行动条件。不能只摘取俏皮台词。 |
| 节奏 | 三章现实铺垫后进入游戏；训练连续推进、逐次呈现修正；技能突破之后很快遇到钱的限制。第1–10章。 | 这是开篇节奏观察，不能据此概括全书高潮分布。 |
| 主题 | 能否把令人羞耻的谋生能力转成可公开承认的职业价值；照料能否不损害被照料者的自主性。第1–4章。 | 属于研究提出的问题，尚非作者意图或用户价值偏好的定论。 |
| 连续性 | 试玩一个月；技能训练与升级分开；委托已接但未完成；第2/5/6章连续动作中出现“萧翎”字样。第2章 L97，第5章 L292，第6章 L331，第10章 L477–485。 | 保留源文异常，不把异写登记为跨书同一人。 |

## 当前未解与保留意见

- **本批结束时**：生活目标尚未完成，奥德的失物任务未说明，采草条件也尚未全部满足。这不是全书结尾状态；旧[剧情线记录](legacy-threads.md)有后续分段信息。
- 训练之所以有说服力，是因为失败可归因且改善可观察；若只保留数字增长，就丢掉了机制。
- 身体、贫困和人物善恶常有直接评价。原创时可选择减少解释、增添不同人物的反应；这只是可试验的控制项，未写成你的风格规则。
- 第9章末尾的剩余血量与掉血概述口径不完全一致；应保留原定位，不为使系统看起来整齐而改写文本。
